В проекте реализован полный цикл работы с данными маркетплейса через SQL:
1) Анализ структуры и качества данных: выявление аномалий и пропущенных значений.

2)Создание витрин данных: разработка агрегирующей таблицы product_user_features для аналитики.

3)Ad hoc анализ: решение четырёх практических задач по изучению покупательского поведения клиентов разных регионов.
