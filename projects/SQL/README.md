## Horoshilov_SQL_(Vitrina_marketplace)  
Анализ данных маркетплейса: разработка витрины продуктовых метрик  
* **Цель:** Помочь команде маркетинга лучше понять поведение пользователей и повысить долю платящих игроков.
* * **Задачи исследования:**
  * Проверка структуры и качества данных: выявление аномалий и пропущенных значений.
  * Создание витрин данных: разработка таблицы `product_user_features` для аналитики.
  * Ad hoc-исследование: решение четырёх практических задач по изучению влияния региональных факторов на покупки.
  * * **Результат:** Подготовлен отчёт с рекомендациями для настройки рекламы и персонализации предложений.

#Horoshilov_SQL_(Secrets_Temnolesiy)  
В проекте изучена монетизация мобильной игры. Определены:  
1. Доля игроков, покупающих внутриигровую валюту «Райские лепестки».
   
2. Влияние выбора расы персонажа на склонность к платежам.
   
3. Детальный путь пользователя при покупке эпических предметов через рекламу.
