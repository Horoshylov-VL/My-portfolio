## Horoshilov_SQL_(Vitrina_marketplace)  
Анализ данных маркетплейса: разработка витрины продуктовых метрик  
* **Цель:** Помочь команде маркетинга лучше понять поведение пользователей и повысить долю платящих игроков.
* **Задачи исследования:**
  * Проверка структуры и качества данных: выявление аномалий и пропущенных значений.
  * Создание витрин данных: разработка таблицы `product_user_features` для аналитики.
  * Ad hoc-исследование: решение четырёх практических задач по изучению влияния региональных факторов на покупки.
* **Результат:** Подготовлен отчёт с рекомендациями для настройки рекламы и персонализации предложений.

## Horoshilov_SQL_(Secrets_Temnolesiy) 
Исследование монетизации мобильной игры «Райские лепестки» 
* **Цель:** Выяснить, какая часть аудитории покупает внутриигровую валюту за реальные деньги, есть ли зависимость доли платящих от игровых характеристик персонажей и как устроен процесс покупки эпических предметов.
* **Задачи исследования:**
  * Определение доли платящих игроков (*paying share*) среди всей базы.
  * Изучение зависимости этой доли от выбранной игроком расы персонажа.
  * Детальный разбор воронки покупок эпических предметов через рекламные интеграции внутри игры.
* **Результат:** Полученные данные помогут команде разработки оптимизировать игровые механики и таргетинг рекламных кампаний.
