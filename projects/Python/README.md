# Horoshilov_Loyalty_Afisha  
В рамках этого проекта был проведён полный цикл работы аналитика от подключения к базе данных до визуализации результатов (*EDA-анализ*).  

## Цель проекта  
Помочь команде маркетинга платформы «Яндекс Афиша» повысить долю клиентов, которые совершают повторные покупки билетов. Для этого необходимо выявить факторы, влияющие на возврат пользователя.  

## Задачи исследования  
- *Подключение* к БД SQL и первичное знакомство со структурой таблиц.
- Выгрузка релевантных данных и перенос их в датафреймы pandas.
- Предобработка данных: очистка аномалий, работа с пропусками и создание новых признаков (**feature engineering**).
- Корреляционный анализ профиля пользователя с помощью библиотеки phik.
- Визуализация ключевых метрик и факторов лояльности *(matplotlib, seaborn)*.  

## Результаты  
Выявлены наиболее значимые драйверы повторного спроса. Определена оптимальная стратегия сегментации аудитории для персонализации предложений и настройки таргетированной рекламы.

# Horoshilov_rest_analys
# Анализ рынка общепита Москвы: выбор концепции кафе  

## Описание задачи
Подготовить для инвесторов фонда Shut Up and Take My Money рекомендации о формате заведения, месте открытия и ценовой категории на основе анализа открытых данных рынка общепита Москвы.

## Задачи исследования  
- Объединение двух датасетов *(pandas, SQL)*.
- Работа с пропущенными значениями, аномалиями и дубликатами; создание новых признаков.
- Построены визуализации распределения заведений по категориям, административным округам и ценовым сегментам *(matplotlib, seaborn)*.
- Проведено исследование влияния локации (центр/спальный район) на средний чек.
- Сформированы рекомендации для инвесторов фонда Shut Up and Take My Money.

## Результаты  
На основе анализа выявлены ключевые факторы успеха заведений общепита в Москве. Подготовлены рекомендации для инвесторов фонда *Shut Up and Take My Money*, которые позволят выбрать оптимальный формат заведения, ценовой сегмент и локацию, а также снизят риски запуска нового проекта.
