# Horoshilov_Loyalty_Afisha  
В рамках этого проекта был проведён полный цикл работы аналитика от подключения к базе данных до визуализации результатов (*EDA-анализ*).  

## Цель проекта  
Помочь команде маркетинга платформы «Яндекс Афиша» повысить долю клиентов, которые совершают повторные покупки билетов. Для этого необходимо выявить факторы, влияющие на возврат пользователя.  

## Задачи исследования  
- *Подключение* к БД SQL и первичное знакомство со структурой таблиц.
- Выгрузка релевантных данных и перенос их в датафреймы pandas.
- Предобработка данных: очистка аномалий, работа с пропусками и создание новых признаков (**feature engineering**).
- Корреляционный анализ профиля пользователя с помощью библиотеки phik.
- Визуализация ключевых метрик и факторов лояльности *(matplotlib, seaborn)*.  

## Результаты  
Выявлены наиболее значимые драйверы повторного спроса. Определена оптимальная стратегия сегментации аудитории для персонализации предложений и настройки таргетированной рекламы.

4. Выполнен корреляционный анализ с использованием библиотеки phik. Определены наиболее сильные взаимосвязи между признаками профиля пользователя и количеством совершенных им заказов.

5. Построены визуализации распределения ключевых метрик и факторов лояльности.

# Horoshilov_rest_analys
Исследовательский анализ данных (EDA): Выбор концепции кафе в Москве  
В проекте выполнен полный цикл анализа открытых данных о заведениях общественного питания Москвы:  

1. Загрузка и объединение двух датасетов (pandas, SQL).  

2. Предобработка данных: работа с пропусками, аномалиями и дубликатами; создание новых признаков.  

3. Визуализация распределения заведений по категориям, районам и ценовым сегментам (matplotlib, seaborn).  

4. Анализ популярности сетевых брендов и их рейтинга.  

5. Исследование зависимости среднего чека от расположения заведения (центр vs спальный район).  
Рекомендации для инвесторов основаны на выявленных трендах и помогут снизить риски при запуске нового проекта.
