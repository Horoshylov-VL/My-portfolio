#Horoshilov_Loyalty_Afisha
Исследовательский анализ: лояльность пользователей "Яндекс Афиша"  
В рамках исследовательского анализа данных платформы «Яндекс Афиша» был проведён полный цикл работы аналитика:  

1. Подключение к базе данных SQL и первичное знакомство со структурой таблиц.

2. Выгрузка релевантных данных с помощью SQL-запросов и перенос их в датафреймы pandas.

3. Проведена предобработка данных: очистка от аномалий, работа с пропущенными значениями и создание новых признаков (feature engineering).

4. Выполнен корреляционный анализ с использованием библиотеки phik. Определены наиболее сильные взаимосвязи между признаками профиля пользователя и количеством совершенных им заказов.

5. Построены визуализации распределения ключевых метрик и факторов лояльности.
