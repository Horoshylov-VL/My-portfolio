Исследовательский анализ: лояльность пользователей "Яндекс Афиша"  
Описание:  
Проект по выявлению драйверов повторного спроса на платформе «Яндекс Афиша» с помощью SQL-запросов и Python-библиотек pandas, phik, matplotlib. Проведён корреляционный анализ признаков пользователя для формирования рекомендаций бизнесу.
